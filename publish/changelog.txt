# General

bumped neoforge version to .262

# Attribute Module

renamed `double_jump` -> `multi_jump` because it allows for more than two jumps, and I'm as pedantic as the person suggesting it
added `immune_to_life_steal` tag to disable life steal effect on selected entity types

# Bonus Module

removed generics from `Bonus`
renamed `Bonus` -> `BonusEffect` to better illustrate its purpose
renamed `BonusRegistries.SERIALIZER` to `BonusRegistries.EFFECT_SERIALIZER`

# Component Module

reworked Glyph effects to use a registry instead of event based registration.
changed Glyph Effects to only be available from translated component instead of everything
changed Glyph Effect format from `§<key>` to HTML format: `<[location] (paramKey=paramValue)*>(styledText)</[location]>`
added Glyph Effect parameters (amplitude and scale for wave and shake as well as origin, type, speed and spacing for rainbow)

# Core Module

fixed MathHelper using Mth#clamp to check for values in a range
removed MathHelper#getRandomOffsetForPos
moved considerable amounts of helper methods into interface injected patches. prefer those over the helper methods

# Enchantment Module

fixed description shift notice not being shown

# Mana Module

added overlay compatibility

# Overlay Module

removed mana dependency

# Publish Module

fixed changelog text being formatted wrongly

# Shader Module

added `UniformRenderStateShard` allowing you to set uniforms directly from the RenderType.
deprecated `RegisterUniformsEvent` in favor of the StateShard
